坐月子 (zuò yuèzi) — Chinese postpartum confinement, observed alongside [[Malay Pantang]] across the same 44-day [[MOC - Postpartum Journey|journey]]. TCM holds that birth leaves the body in a "vacant-cold" (虚寒) state — Blood (血) and Qi (气) both depleted, requiring warmth, tonification, and stillness to refill before the body naturally closes again.

- [[Chinese Rationale — Phase 1 (Days 1-7)]] / [[Chinese Practices — Phase 1 (Week 1)]] — complete rest
- [[Chinese Rationale — Phase 2 (Days 8-21)]] / [[Chinese Practices — Phase 2 (Weeks 2-3)]] — building strength
- [[Chinese Rationale — Phase 3 (Days 22-44)]] / [[Chinese Practices — Phase 3 (Weeks 4-6)]] — return to vitality

Core recurring elements: [[Ginger (Halia Tua · 老姜)]], [[Sesame Oil (麻油)]], [[Red Dates · 红枣 (Chinese Jujube)]], [[Dang Gui (当归)]], [[四物汤 (Sì Wù Tāng)]], and [[月子茶 (Red Date & Longan Tea)]] (see [[Red Date Tea & Breastfeeding]] for safety).
